# C++ Algorithms & Data Structures Collection
[Polski](./README_PL.md)
A collection of my own implementations of classic algorithms, data structures, and math-logical programs written in C++ over the past 6 years.
The project serves as a base for testing code optimization, experimenting with memory management, and exploring advanced language mechanisms.
## Main categories of algorithms
### Mathematics and optimization
* **Sieve of Eratosthenes** - efficient prime number search
* **Euclidean Algorithm** - calculating the greatest common divisor (GCD)
* **Golden Number & Factorial** - calculations on proportions and complex iterative/recursive operations
* **Limit Interpretation** - programmatic analysis of limits
### Operations on Sequences
* **Fibonacci / Tribonacci Sequence** (various implementation options: loops, generating multiple values)
* **Increasing-Decreasing Sequences** (finding maxima, positioning in sets, parsing data from files)
### Working with arrays and memory
* **Kadane's Algorithm (Segment Sum)** - finding the subarray with the largest sum (complexity O(N))
* **One- and two-dimensional arrays** - pointer operations and dynamic allocation
### Tools
* **RNGenerator** - proprietary pseudorandom number generator system (PRNG)

## Environment
* Language: **C++**
* Architecture: The project is based on a single solution (Visual Studio Solution `.slnx`) that ties independent console applications into a cohesive whole.

## How to run selected algorithms
1. Clone the repository to your drive.
2. Open the `CPP-Algorithms-Collection.slnx` file in Visual Studio.
3. In the *Solution Explorer* window, right-click on the project you're interested in (e.g., `Sieve of Eratosthenes`) and select **"Set as StartUp Project"**.
4. Compile and run (F5).
